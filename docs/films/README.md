# Explainer films

Short animated presentations of Sardeenz, drawn, scored and narrated entirely in code with the
[Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) style library.

| Film | Style | Watch | Notes |
| ---- | ----- | ----- | ----- |
| Every Gigabyte (69 s) | Assembly-Line Diagram | [`sardeenz-cannery/sardeenz-cannery.mp4`](sardeenz-cannery/sardeenz-cannery.mp4) | [treatment](sardeenz-cannery/TREATMENT.md), [facts](sardeenz-cannery/FACTS.md), [credits](sardeenz-cannery/CREDITS) |
| Twenty-Four Cubes (67 s) | Isometric Infographic | [`sardeenz-iso/sardeenz-iso.mp4`](sardeenz-iso/sardeenz-iso.mp4) | [treatment](sardeenz-iso/TREATMENT.md), [facts](sardeenz-iso/FACTS.md), [credits](sardeenz-iso/CREDITS) |

Each folder holds the film, its poster, subtitles, the treatment, a fact sheet listing where the
metaphor simplifies, credits for third-party material, and the source with a one-command
`build.sh` (needs the Lemo-Opuscar library, Node 20+, Python 3.11+ and ffmpeg 7+).
